# React CRUD with JSON Server

User management practice with a local JSON dataset and React interface.

## Project structure

- `db.json`
- `src/components/UserManagement.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/curd-with-jsonServer.git
cd curd-with-jsonServer
```

Start the JSON API using the configured package script or a compatible JSON Server version, then launch the React development server. Match the API URL in the source.
